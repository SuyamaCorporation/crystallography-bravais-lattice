# ブラベ格子 結晶構造 Canvas 2D ビューア

14種のブラベ格子を等角投影 Canvas 描画で可視化する材料科学・鉱物学教育ツール。

## 機能

- 7結晶系 × 14種のブラベ格子（SC/BCC/FCC/HCP/斜方/単斜/三斜 等）を完全網羅
- 等角投影法による3D格子構造の2D描画（頂点・体心・面心・底心原子を色分け）
- 格子定数 a/b/c (Å) と β 角をスライダーでリアルタイム調整
- 配位数・充填率・代表元素を表示
- 結晶系フィルタと14種一覧グリッドから直接選択可能

## 技術メモ

- 等角投影: (a, b, c) 座標を 2D スクリーン座標に変換（iso projection vectors）
- 単斜晶系は β 角による b ベクトルの傾きを反映
- 単体 HTML + Tailwind CDN
